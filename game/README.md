# Special Ops

Created with VICTUS from the 3D Scene template.

- `victus.project` - project settings
- `assets/` - source assets (each with a `.meta` file; commit both)
- `assets/scripts/` - Luau gameplay scripts, hot reloaded while playing in the editor
- `scenes/` - scenes (`.vscene`, JSON)
- `.victus/` - import cache and development save games, safe to delete

Open the folder in the VICTUS editor, or run `victus run <this folder>`.
